## 2. What challenges and limitations did you identify when reviewing AI-generated Markdown?

A major limitation is that fluent documentation can appear complete even when it contains inaccurate technical details. An AI-generated README might refer to a package that is not installed, describe an output file that the script does not create, or provide a command with the wrong relative path. Markdown can also contain headings, lists, and fenced code blocks that look reasonable in plain text but render poorly when previewed. These issues matter because readers depend on the documentation to reproduce the project.

For this assignment, the proposed verification process is to compare each instruction with the actual R script, check that the dataset is synthetic, and inspect the rendered README in GitHub. The R Markdown file should be knitted in RStudio or Posit Cloud to confirm that the R chunks execute and that any tables and figures appear as intended. Numeric results should be independently checked against the underlying synthetic records rather than accepted because AI described them. A final manual spot-check should confirm consistent headings, working relative links, and clear explanations. These are verification steps to complete, not claims that the code has already been run or that every preview has passed.

## 3. What did you learn about ethical AI use and how would you improve this workflow?

The most important lesson is that AI can improve the clarity and speed of technical writing, but accountability remains with the person submitting the work. Ethical use requires identifying the AI tool, documenting the prompts and substantive revisions, and distinguishing AI-assisted prose from calculations or results that have been independently verified. The assignment also restricts the project to synthetic data, which avoids exposing personal or confidential information in prompts or repository files.

Next, I would render the README, knit the R Markdown report, cross-check a sample of results, and revise unclear wording.
